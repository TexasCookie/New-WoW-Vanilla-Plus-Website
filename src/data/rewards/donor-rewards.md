Your donations keep VanillaPlus alive. Server hosting, DDoS protection, development tools, and dedicated testing infrastructure all cost real money. By donating, you directly fund the server's uptime and the continued development of new content, bug fixes, and quality-of-life improvements. Every dollar goes back into making VanillaPlus the best it can be.

## Reward Tiers

### Supporter — $5+
- Unique in-game title: **"of the Vanguard"**
- Donor-only chat channel access
- Custom forum badge

### Champion — $15+
- All Supporter rewards
- Exclusive non-combat pet: **Vanguard Hatchling**
- Character name priority on new realms
- Custom forum badge upgrade

### Hero — $30+
- All Champion rewards
- Exclusive mount: **Vanguard Steed** (unique model, matches all races)
- Priority queue during high-population periods
- Early access to PTR builds

### Legend — $50+
- All Hero rewards
- Exclusive transmog set: **Vanguard Regalia** (account-wide)
- Custom guild tabard design consultation
- Name reserved in the VanillaPlus Credits
- Monthly developer Q&A access

### Architect — $100+
- All Legend rewards
- Work with the dev team to design a minor in-game item (name and tooltip)
- Permanent priority queue
- Exclusive Architect forum badge and Discord role
- Name prominently displayed in the VanillaPlus Credits
